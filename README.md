# 업종별 기업 체감경기 대시보드

**질문:** 경기 변동에 가장 민감하게 반응한 업종은 어디인가?

**배포 URL:** [https://앱이름.streamlit.app]

## 데이터
- 한국은행 「기업경기조사」 업종별 기업경기실사지수 (국가통계포털 KOSIS)
- 신분류 DT_512Y007 (2009.08~), 구분류 DT_512Y001 (2003.01~2009.07)
- 지수 = 100 + 「좋음」 응답 비중(%) − 「나쁨」 응답 비중(%)
- 자료 내려받은 날: 2026-11-16

## 구성
- 변동성(표준편차), 경기 민감도(전산업 대비 회귀), 낙폭, 위기 비교(금융위기·코로나)
- 왼쪽 위젯으로 분류체계와 기간을 바꾸면 숫자와 차트가 함께 바뀝니다.

## 실행
pip install -r requirements.txt
streamlit run app.py
