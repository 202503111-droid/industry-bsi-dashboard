# 업종별 기업 체감경기 대시보드

> 경기 변동에 가장 민감하게 반응한 업종은 어디인가?

한국은행 「기업경기조사」의 업종별 기업경기실사지수(업황 BSI)로, 10개 업종이 전산업 경기와 얼마나 함께 움직였는지 비교하는 Streamlit 대시보드입니다.

**배포 주소:** [https://앱이름.streamlit.app]  ← 실제 주소로 바꾸세요

## 기능
- **경기 민감도**: 전산업 업황이 1p 움직일 때 각 업종이 몇 p 움직였는지(회귀 기울기)와 설명력(R²)
- **추이**: 직접 고른 업종의 월별 업황 선 그래프(최대 8개, 처음에는 선택 없음)
- **변동성**: 업종별 업황 표준편차(출렁임)
- **낙폭**: 고점 이후 최대 하락 폭(3개월 이동평균 선택 가능)
- **민감도 1위 안정성**: 월별 자료를 12개월 단위로 2,000번 다시 뽑았을 때 민감도 1위가 1위로 유지되는 비율(블록 부트스트랩)
- **용어 풀이**: 민감도, R², 출렁임, 낙폭, 안정성을 쉬운 말로 설명하는 펼침 상자
- 사이드바에서 분류체계(신분류/구분류), 시작·종료 월을 바꾸면 모든 숫자와 차트가 함께 바뀝니다.
- 화면 하단에 결론과 "이 결론의 한계", "출처와 집계 기준"이 데이터에 맞춰 표시됩니다.

## 데이터
- 출처: 한국은행 「기업경기조사」, KOSIS 국가통계포털
- 신분류 DT_512Y007(2009.08~2026.10), 구분류 DT_512Y001(2003.01~2009.07). 두 분류는 업종 구성이 달라 직접 이어 붙이지 않습니다.
- 지표: 업황 BSI = 100 + 좋음(%) − 나쁨(%)
- 다운로드일: 2026-11-16
- 파일: `data/bsi_industry.csv`

## 실행

```
pip install -r requirements.txt

```

## 한계
BSI는 응답 기업의 체감을 묻는 설문 지표이며 실제 매출·생산이 아닙니다. 전산업 지수에 각 업종이 포함되어 있고, 1위 업종은 분석 기간과 분류체계에 따라 바뀔 수 있으며, 앱은 민감도 1위의 유지 비율을 함께 보여 줍니다. 자세한 내용은 앱의 "이 결론의 한계"를 참고하세요.

## AI 사용
코드 작성·검토와 문서 초안에 Claude(Anthropic)를 사용했습니다.
